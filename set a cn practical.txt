🔥 Viva Questions for THIS Lab
1. What is a VLAN?

A VLAN is a logical network that divides a physical switch into separate broadcast domains.

2. Why do we use VLANs?

For network segmentation, security, management, and reducing broadcast traffic.

3. What is VLAN 10?

A logical VLAN identified by VLAN ID 10.

4. What is VLAN 20?

A logical VLAN identified by VLAN ID 20.

5. Can VLAN 10 communicate with VLAN 20 using only a Layer 2 switch?

No.

A Layer 3 device is required.

6. What is a trunk port?

A trunk port carries traffic belonging to multiple VLANs between network devices.

7. What protocol is used for VLAN tagging?

IEEE 802.1Q.

8. What is an access port?

A switch port that normally carries traffic for a single VLAN.

9. What is the difference between access and trunk?

Access = one VLAN
Trunk = multiple VLANs

10. Why is the switch-to-switch link a trunk?

Because VLAN 10 and VLAN 20 both need to cross the link between the switches.

11. Why doesn't VLAN 10 communicate with VLAN 20 before routing?

Because they are separate Layer 2 broadcast domains.

12. What is inter-VLAN routing?

Routing traffic between different VLANs.

13. What is Router-on-a-Stick?

A method of inter-VLAN routing where a single physical router interface uses multiple subinterfaces, with each subinterface representing a VLAN.

14. Why create G0/0.10?

It is the router subinterface associated with VLAN 10.

15. Why G0/0.20?

It is the router subinterface associated with VLAN 20.

16. What does this do?
encapsulation dot1Q 10

It associates the subinterface with VLAN 10 using IEEE 802.1Q tagging.

17. What is the default gateway for VLAN 10?
192.168.10.1
18. What is the default gateway for VLAN 20?
192.168.20.1
19. Why does a PC need a default gateway?

To communicate with devices outside its local IP network.

20. What happens if the PC has the wrong gateway?

It may communicate within its own subnet but cannot properly reach other networks.

21. What is the difference between VLAN and subnet?

A VLAN is a Layer 2 logical segmentation, while a subnet is a Layer 3 IP network division. In normal designs, each VLAN is commonly associated with its own IP subnet.

255.255.255.240
23. How many addresses are in a /28?
16

14

256 - 240 = 16

192.168.5.32/28

192.168.5.47

192.168.5.33 – 192.168.5.46
